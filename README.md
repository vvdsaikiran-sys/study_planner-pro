# 📚 Study Planner Pro

## Overview

Study Planner Pro is a full-stack web application that helps students manage their study tasks. Users can register, log in, create tasks, set priorities and due dates, and track their study progress.

---

## Features

- User Registration
- User Login
- Add Study Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Task Priority (High, Medium, Low)
- Due Date
- Dashboard Statistics
- Clear Completed Tasks
- Logout
- About Page

## How to Run

1. Install Node.js.
2. Start Apache and MySQL using XAMPP.
3. Import the `study_planner` database into MySQL.
4. Install dependencies:

```bash
npm install
```

5. Start the server:

```bash
node server.js
```

6. Open `index.html` in your browser.
